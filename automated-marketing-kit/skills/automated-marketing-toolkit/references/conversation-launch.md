# Communities and high-intent threads
## Produce a batch before refining the strategy
Recover the product facts, audience and browser choice already supplied. Begin discovery and drafting without another strategy interview unless a missing fact changes the claims. A useful default pass targets 20–40 distinct examples across 3–6 relevant communities and 6–10 review drafts, adjusted to the user's scope and the evidence. Targets guide breadth; do not invent matches to reach them.

Batch independent supported searches. In native Reddit search, use the actual help/question flair where available and task-specific language; broad terms such as “context” can mostly return showcases and billing complaints. Collect title, original permalink, visible age and source before opening every result. Deduplicate early. Screen obvious mismatches from those cards and mark unopened sources unverified. Then read the strongest original posts, clarifications and relevant replies before drafting.

Save an initial 3–5 useful comments as soon as their context is read, then continue across the remaining communities. Do not turn one promising thread into the entire run. Check community rules once per proposed interaction type in the pass and reuse that evidence; recheck before publication or when rules/notices change. A missing posting prerequisite holds publication, not all research and review drafting. Keep counts of discovered, fully read, drafted, held and skipped separate.

## Up to ten relevant launch communities
Start from the buyer's role, task, tools and vocabulary. Search broad and niche sources using available tools. For each shortlisted community save community URL, rule URL/date, sample thread URLs, actual audience/job evidence, useful contribution, promotional/AI/automation restrictions if stated and research-only/participation/skip decision. A shorter relevant shortlist beats ten broad forums. No membership or virality forecast is needed.

## Search patterns
`site:reddit.com/r/[community] "looking for" "[task]"`
`site:reddit.com/r/[community] "recommend" "[tool category]"`
`"[alternative]" "missing" "[required capability]"`
`"[task]" "spreadsheet" "manual"`
Vary exact language from evidence. Search engines can miss recent posts; use native search where legitimately available. Date filters are discovery aids: verify dates and full context at the original source. Never bypass logins, rate limits, robots/access restrictions or moderation.

## Qualification
Record original permalink, observation date, source date, concise problem evidence, request, capability fit, decisive limit, rules status and whether a helpful response is still timely. Read relevant replies to see whether the need is resolved. Topic similarity alone does not create intent. Requesting a tool is stronger than general commentary, but only if your product supports their actual constraints.

## Heuristic score
Pain 0–3 + intent 0–3 + fit 0–3 + freshness 0–2 + helpfulness 0–2 = 0–13. High 10–13, medium 7–9, low 0–6; not purchase probabilities. Fake/example URLs, unread context, no useful answer and unsupported fit cannot become genuine reply candidates. Rules unknown/disallowed for the proposed interaction, thread closed/unknown and prior contact yes/unknown hold publication regardless of score. A review draft can retain unresolved publication checks, clearly labeled; known promotion restrictions require no product mention or skip. Current rules and source context must be checked again before an external action; the score is not a permission token.

## No access
Public research does not need the purchaser to create a Reddit account. Use accessible public pages/search results as discovery; sources not opened remain unverified. If an available browser has an existing session, reuse it only within the user's authorized task. If public access is unavailable, return searches, source gaps and a copyable review table. Do not require an account for research or drafts. If the user later requests posting without a session, provide the official setup steps, let them complete credentials and CAPTCHA themselves, and resume authorized work once legitimate access is available; do not claim the agent automatically logged in.
