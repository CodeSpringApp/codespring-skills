# Automated Marketing Kit map — install one, expand when useful
`skills/automated-marketing-toolkit` is the self-contained starting workflow. Install or attach it first. Its bundled references and assets take a campaign from product facts to an accurate execution handoff.

Specialists:
- `instant-ai-researcher`: deeper market/alternative evidence and cited brief.
- `ai-positioning-expert`: explicit audience, alternative and message decisions.
- `automated-marketer`: conversation scoring CSV, reply queue and local helper tools.
- `reddit-community-finder`: up-to-ten launch shortlist, with a 20-community starting directory.
- `humanizer`: truthful voice editing without fake experience or forced slang.

Templates are working forms to fill with real facts, not product claims. Examples are explicitly fictional and never live leads. `claude-upload/` holds one self-contained ZIP per skill for supported Claude app uploads. All source guidance remains downloadable Markdown in this pack. No global install or authentication flow is required.
